# Bateria (resultado mais recente)

Este diretório guarda as imagens da **última bateria rodada**. Cada bateria
**sobrescreve tudo** aqui — não versionamos por data. É o validador final: é a
bateria que diz se temos um binário estável o bastante para virar uma release.

O script de bateria (host/device) deve escrever em `docs/batery/`; os links em
`docs/game_status.md` apontam para cá (`batery/<jogo>_N.png`).
