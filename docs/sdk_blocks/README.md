# Blocos de SDK repetidos entre jogos

Um documento por família de bloco que aparece com os mesmos opcodes em vários jogos (código de biblioteca do SDK). Cada um traz a listagem SH4 de cada jogo, tirada dos dumps do JIT. Contexto e plano: `docs/native_sdk_code.md` (4.125) e `docs/sh4_threading_model.md`.

Regenerar (dcbat_off antes de dcbat; jogo usa o primeiro dump em que aparece):

```bash
python3 tools/sdk_blocks_doc.py docs/sdk_blocks /mnt/1TB/dcbat_off/*/jit-*.txt \
    $(ls -r /mnt/1TB/dcbat/*/jit-*.txt)
```
